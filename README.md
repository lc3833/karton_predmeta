Aplikacija za digitalno vođenje kartona predmeta za Fakultet organizacionih nauka, Softversko inženjerstvo i veštačku inteligenciju.

Uputstvo za pokretanje projekta:

1.  Uverite se da imate pokrenut MySQL server na portu `3306`.
2.  Podesite `username` i `password` u `application.properties`.
    Nakon toga aplikacija je spremna za pokretanje.
3.  Pristupite aplikaciji na: `http://localhost:8080/Java.html`
4.  Swagger dokumentacija je dostupna na: `http://localhost:8080/swagger-ui/index.html`
